# NovelKeeper

[![test](https://github.com/ru-114514/NovelKeeper/actions/workflows/test.yml/badge.svg)](https://github.com/ru-114514/NovelKeeper/actions/workflows/test.yml)

**手持ちのノベルゲームを、ひとつの画面で起動・管理するツールです。**
プレイ時間は自動で記録され、批評空間（ErogameScape）の「プレイ済」「クリア日」「得点」とも連動できます。

> ※ 批評空間の公式ツールではありません。

---

## できること

| | |
|---|---|
| 🎮 **まとめて起動** | 持っているゲームを一覧にして、「起動設定」欄のダブルクリックで起動。コンプリートボックスなど、1作品に複数の起動ファイルも登録できます |
| ⏱ **プレイ時間を自動で記録** | ゲームを起動するだけで計測。デスクトップや Steam から起動しても数えます。放置している時間（寝落ちなど）は、さかのぼって除外できます |
| 📊 **プレイ状況のレポート** | 今日・3日・1週間・1か月・全期間、または好きな期間を選んで、プレイ時間のグラフ・カレンダー・遊んだ作品を確認できます。前の期間との比較や、最も遊んだ日なども分かります |
| 🖼️ **投稿用の画像を作る** | 起点の日から1か月／1年のプレイ記録（総プレイ時間・クリア数・点数・遊んだ作品の画像・マイベストブランドなど）を、好きなパネルで組み立てて jpg に出力できます。SNS などへの投稿用です |
| 📋 **進み具合の管理** | 未プレイ／プレイ中／プレイ済／中断 で整理。絞り込みや並び替えもできます |
| 🔄 **批評空間と連動** | 批評空間に登録済みの作品をまとめて取り込み。得点・プレイ済・所持・総プレイ時間・感想など、得点登録ページの項目をツールで編集して、そのまま批評空間へ反映できます |
| 🖼 **作品の画像** | 詳細欄に作品の画像を表示します（表示しない設定もできます） |
| 🔍 **起動ファイルを自動で探す** | ゲームのフォルダや Steam から、各作品の exe を自動で見つけます。見つからない作品は、ショートカットをドラッグ＆ドロップするだけ |
| 🎨 **見やすく調整** | ダーク／ライトのテーマ、一覧の拡大縮小、表示する列の追加（批評空間の平均値・データ数など）ができます |

## はじめかた（5分ほど）

### 1. ダウンロードして起動する

1. 受け取った zip を、好きな場所に展開します（例：`C:\Tools\NovelKeeper`）。
2. `NovelKeeper.exe` をダブルクリックします。インストールは不要です。

**「Windows によって PC が保護されました」と出たら**
個人で作ったアプリなので、最初だけ警告が出ます。「詳細情報」→「実行」を押してください。
それでも起動しないときは、`NovelKeeper.exe` を右クリック →「プロパティ」→ 下のほうの「許可する」に☑ →「OK」。

**配布版は2種類あります**
- `NovelKeeper_vX.Y.Z.zip`（通常版・約70MB）…… 何も入れなくても動きます。
- `NovelKeeper_vX.Y.Z_lite.zip`（軽量版・約1MB）…… [.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0)が入っているPCで動きます。

zip が改ざんされていないか確かめたいときは、配布元が別に伝えた `SHA256SUMS` の値と、`Get-FileHash .\NovelKeeper_vX.Y.Z.zip` の結果を比べてください（zip の中の `SHA256.txt` は、壊れていないかの確認用です）。

### 2. 批評空間にログインする

「**ログイン設定**」タブで、批評空間のIDとパスワードを入れて「保存してログイン」を押します。
パスワードは Windows の機能で暗号化し、このPCの中だけに保存します。

### 3. 自分の作品を取り込む

「**批評空間連携**」タブ →「**⇩ 批評空間から一括取り込み…**」。
批評空間に登録している作品が一覧に入ります（プレイ済・得点・感想なども一緒に入ります）。

### 4. 起動ファイルを自動で探す

「**ゲーム起動設定**」タブで、ゲームを入れているフォルダを追加 →「**🔍 実行ファイルを自動検出…**」→「検出開始」→「☑ した作品に設定する」。
exe を1つに特定できた作品には、最初から☑が付いています。

### 5. 残りはドラッグ＆ドロップ

「**一覧**」タブに戻り、「表示」で「**起動設定が未設定**」を選びます。
各作品の「起動設定」欄にある「⬇ ここにドロップ」へ、デスクトップのショートカットや exe をドラッグしてください。

これで準備完了です。

## ふだんの使い方

- **遊ぶ**：作品を選んで「▶ 起動」、または一覧の「起動設定」欄をダブルクリック（起動設定済みの欄は緑色です。右端の ▼ で、起動するもの（収録作など）を選び替えられます）
- **管理者権限が必要なゲーム**：「起動設定」欄を右クリック →「管理者権限で起動」（Windows の確認画面が出ます）。初回に「今後、この作品は確認なしで管理者権限で起動する」を選ぶと、通常の起動も管理者権限になります。外すときは同じ右クリックから。すべての作品を対象にする設定と、一括で外すボタンは「詳細設定」にあります（※ Steam・DMM Game Player など URL 形式の起動は、管理者権限にできません。通常権限で起動します）
- **クリアしたら**：右の詳細欄で「プレイ済」に☑、終了日・得点を入れて「保存」。批評空間にも反映されます
- **感想などを書く**：詳細欄の「プレイ時間・購入」「動作環境」「感想」を開いて入力し「保存」。変えた項目だけが批評空間に送られます
- **批評空間で付けた記録を取り込む**：「⇅ 批評空間と同期」（中央値・平均値なども最新になります）
- **新しく買った作品を追加**：「＋ 作品を追加」でタイトル検索（空白で区切った語をすべて含む作品を探します。ひらがな・カタカナ、全角・半角、長音「ー」の表記ゆれ、ブランド名でも見つかります）
- **購入額を残す**：詳細欄の「プレイ時間・購入」に、作品ごとの購入額を任意で入力できます（3桁ごとの「,」は自動で入ります）。一覧の「購入額」列は、「詳細設定」の「一覧の列」で非表示にできます
- **項目ごとに採点する（任意）**：「詳細設定」の「任意評価基準」で「項目ごとの採点を使う」をオンにすると、詳細欄の得点欄の下で、項目ごとに採点できます。合計が「自分の得点」に自動で入ります（初期はオフで、これまでどおり得点欄に直接入力します）
  - 項目の名前と最高点は、「詳細設定」で決めます（全作品で共通）。最高点の合計をちょうど 100 にしないと保存できません。「最高点を均等に振り分ける」も使えます
  - 採点が項目の最高点を超えたり、一部の項目だけ入力して保存しようとしたりすると、赤字でエラーが出て、保存も批評空間への反映もされません
  - 批評空間に送るのは、合計の得点だけです。項目別の点数は、ツールにだけ残ります
  - 得点だけ入れてある過去の作品は、そのまま残ります（項目を入力して保存したときだけ、得点が合計に置き換わります）
  - オフにしても、項目の設定と点数は消えません（詳細欄の見た目はこれまでどおりになります）
  - 登録後に基準を変更した作品は、一覧の「得点」が赤い枠で囲まれ、採点し直すまで残ります。批評空間の得点を取り込んで、項目の合計と食い違った作品も同じです（同期のあと、一覧を知らせるダイアログも出ます）。「一覧の列」で「採点:項目名」の列を表示すると、項目ごとの点数を一覧で見られます（初期は非表示）
- **買う前の作品を整理する**：「購入前の作品を整理…」（「詳細設定」タブ）で、購入前の作品をまとめて削除できます。得点・感想も消すかは、チェックで選びます（初期は消しません）
- **一覧の「表示」**：すべて／未プレイ／プレイ中／プレイ済／中断／起動設定が未設定／発売前／発売後／購入前／購入確認が必要。発売済みなのに所持が付いていない購入予定の作品は、「購入確認」列が赤く「要確認」と出ます
- **プレイ状況を見る**：「レポート」タブで期間を選びます（「今日」は 0:00〜23:59。「3日」「1週間」「1か月」は今日を含む直近です）。グラフ・カレンダー・作品の各欄は、見出しをドラッグして好きな場所へ動かせます（「並べ方」で、縦3段・横3列にまとめて並べ替えもできます。並べ替えの対象はこの3欄です）。「表示」の「ヒートマップ」「点数×時間」「クリア」を押すと、曜日×時間帯のプレイ時間（濃いほど長い）、点数とプレイ時間の散布図、期間内にクリアした作品と現在の積みゲー本数の欄を追加できます（初期は非表示。動かし方は他の欄と同じです）。作品名をクリックすると、一覧でその作品を開きます
  - 「今月」「今年」ボタンで、月初・年初から今日までを選べます。期間の説明行には「最長の連続」（1日の合計が10分以上プレイした日が続いた数）も出ます
  - 「表示」の「まとめ」「目標」で欄を追加できます（初期は非表示）。「まとめ」は、今年・今月のプレイ時間（前年・前月との差）、プレイした日、作品数、クリア数、最長の連続、いまの連続、直近12か月の月別を表示します（上で選んだ期間には関係なく、今年・今月です）。「目標」は、年間・月間のプレイ時間（時間）とクリア数（本）を入力すると達成率が出ます（0 または空欄は目標なし）
- **クリア数から外す**：過去にクリアして記録を忘れた作品などは、詳細欄の「ゲーム終了日」の下の「クリア数の集計から除外する」に☑して保存します。レポートのまとめ・目標・クリア欄と、投稿設定のクリア数・点数の集計から外れます（プレイ時間はそのまま数えます）。批評空間には送らず、同期でも変わりません
- **投稿用の画像を作る**：「投稿設定」タブで、起点の日と期間（1か月／1年）を選び、「画像出力」で jpg に保存します（初期のファイル名は NovelKeeper_年月日.jpg。横幅は表示中の画面に合わせ、最大1920です）
  - 上部の「背景」で明るい／暗いを切り替えます。マイベストブランドは、「一番プレイしたブランド」／「最高点のブランド」／「任意のブランド」から選べます
  - 「起点の日より前にクリアした作品を除く」（初期はオン）：起点の日より前にクリア済みの作品と、ゲーム終了日が空欄のプレイ済の作品を、プレイ時間・日数・グラフ・カレンダー・最長の1回・最も遊んだ日・作品数・ブランド・作品の欄・前の期間との比較など、プレイ記録の集計すべてから外します（クリア数・点数・積みゲーは作品の状態から数えるので、そのままです）。再プレイした作品だけ、「再プレイを追加…」で☑すると集計に戻せます（作品ごとに保存。すべて選択／すべてクリアのボタンつき）
  - 「作品を隠す…」：クリア済みでない作品でも、☑した作品をプレイ記録の集計から外せます（作品ごとに保存。☑を外すと戻ります）
  - 「＋ パネルを追加」で、総プレイ時間・クリア数・点数・作品の画像とプレイ時間・マイベストブランド・積みゲー・プレイ日数・最長セッション・前期間との比較・日別グラフ・カレンダー・メモ・見出しなどを自由に追加できます。各パネルの ⚙ で項目・タイトル・縦横の大きさ・表示数などを、× で削除を行います
  - パネルは、ボタン以外のどこをつかんでもドラッグ＆ドロップで動かせます。空きがあれば移動し、すでにパネルがある場所に置くと、入れ替えられるときは入れ替え、そうでなければ重なるパネルが下へずれます（ドラッグ中の枠はオレンジ色になります。タイトルの位置には置けません）。カラム数は2〜4で選べます。「初期配置に戻す」で最初の並びに戻せます
  - 縦幅は、64px 刻みの「段」で決まります。中身がパネルに収まらず切れているときは、右上に「⚠」が出ます。押すと必要な段数まで広げます（下のパネルはずれます。画像出力には写りません）
  - 作品を並べるパネルの「列数」は、自動／1〜4を選べます（自動は、パネルの幅に入るだけ並べます）。カレンダーとブランド別ランキングには「表示の列数」があります。タイトルと見出し以外のパネルには「表示位置」（左寄せ・中央寄せ・右寄せ）があり、余白ができるときに中身を寄せます
  - 「今後優先したい作品」は、未プレイ・プレイ中の作品から選びます。候補の一覧（検索つき）でダブルクリックするか「追加」を押すと、下の「選んだ作品」に入ります。各作品の「×」で外し、ドラッグか「▲▼」で並び順を変えられます（10件まで）
  - 一番上のタイトルは、1行目いっぱいの専用パネルです（移動はできません）。文字・フォント・色・サイズ、枠の透過率、画面端まで広げる設定を変えられます
  - 「デザイン設定」で、背景色・パネルの色・文字色・フォント（カラーコード指定）、背景画像、パネル全体の透過率、項目名の大きさ（8〜40。初期は13）を設定できます。フォントを全体で変えると、各パネルで個別に決めたフォントより優先して上書きします
- **並び替え**：列の見出しをクリック（Shift を押しながらで条件を追加）。「⇅ 並び替え…」で、最大3つの条件を指定できます（購入額の未入力は、昇順・降順どちらでも最後です）
  - 「⇅ 並び替え…」の横の「設定1」〜「設定3」で、よく使う並び順をワンクリックで呼び出せます。並び替えの画面の下のプルダウン（「設定1へ保存」など）を選んで OK すると、その並び順が保存されます（絞り込みは含みません）。使っている設定は太字になり、設定ボタンの「×」で解除できます（確認あり）。幅が足りないときは「▼」のメニューから選べます
- **文字のコピー**：一覧以外の画面の文字は、右クリックで「コピー」できます。手で入力する欄は、Enter で確定できます
- **拡大・縮小**：一覧の上で Ctrl＋マウスホイール（Ctrl＋0 で元に戻る）

画面の幅が狭くてボタンが入りきらないときは、右端の「**▼**」から選べます。

### 各タブでできること

| タブ | 内容 |
|---|---|
| 一覧 | 作品の一覧と詳細欄（起動・記録・感想の編集） |
| レポート | 期間ごとのプレイ時間のグラフ・カレンダー・遊んだ作品、時間帯ヒートマップ・点数×プレイ時間・クリアと積みゲー・年間月間のまとめ・目標（欄は、ドラッグで右・下・左・別ウィンドウなど好きな場所に動かせます） |
| 投稿設定 | 起点の日から1か月／1年のプレイ記録を、好きなパネル配置で組み立てて jpg に出力（SNS 投稿用。最長の連続プレイ日数・目標の達成度のパネルもあります） |
| データ出力 | 左のメニューで切り替えます。「バックアップ」…バックアップの設定と操作をすべてここに集約（自動バックアップの設定・今すぐ・戻す・データの検査、zip の書き出し／戻す）。CSV…作品の一覧を CSV に書き出す（「一覧に表示中」または「全作品」。感想を含めるかも選べます。購入前の作品は、「詳細設定」の一覧への表示設定に従います）。総プレイ時間は「12:30:51」の形で、時間が0のものと購入額が未入力のものは空欄です。購入額は最後の列です（「任意評価基準」をオンにしているときは、その後ろに項目別の点数の列が付きます） |
| ログイン設定 | 批評空間のIDとパスワードの登録、ログインの確認 |
| 批評空間連携 | 一括取り込み、同期 |
| ゲーム起動設定 | ゲームのフォルダ・ショートカットのフォルダの登録、実行ファイルの自動検出 |
| 詳細設定 | プレイ時間の数え方、常駐と起動、表示（テーマ・詳細欄の位置・作品の画像・表示倍率）、任意評価基準（項目ごとの採点）、一覧の列（「任意評価基準」がオンのときは「採点:項目名」も選べます）、保存場所・設定ファイル |

一覧に表示する列は「詳細設定」タブの「一覧の列」で選べます。批評空間の項目（平均値・データ数・所持・総プレイ時間・一言感想・長文感想など）を追加できます（一覧の右クリックでも切り替え可）。

## よくある質問

**Q. ×で閉じたのに終わらない**

A. プレイ時間を数えるため、タスクバー右下（通知領域）に残っています。完全に終了するときは、そのアイコンを右クリック →「終了」。  
常駐させたくない場合は「詳細設定」タブの「常駐と起動」で変更できます。

**Q. 「すでに起動しています」と出る**

A. タスクバー右下に NovelKeeper のアイコンがないか確認してください。アイコンをクリックすると画面が開きます。

**Q. プレイ時間が数えられていない**

A. その作品に起動ファイルが設定されているか確認してください。ゲームが「起動ファイルと同じフォルダ」の中で動いていれば、自動で数えます。  
NovelKeeper が起動（または常駐）していない間は数えられません。  
数えられなかった分は、詳細欄の「プレイ時間・購入」→「計測した記録を補正…」で、あとから追加できます（まちがった記録の修正・削除もできます）。計測中の作品は補正できません。

**Q. 感想をツールで書いたのに、批評空間に出ていない**

A. 詳細欄の「保存時に批評空間へ反映する」に☑があるか確認してください。反映できなかった項目は、詳細欄に「未反映の項目」として表示され、次に「⇅ 批評空間と同期」を押したときに反映されます。

**Q. データをバックアップしたい／別のPCに移したい**

A. 「データ出力」タブ →「バックアップ」で、「バックアップを書き出す…」を押します。`NovelKeeper_backup_年月日_時刻.zip` ができます（作品の一覧・プレイ時間・設定が入ります。ログイン情報は入りません）。  
戻すときは、zip を展開せずに「zip から戻す…」で選び、確認画面で作品数を確かめて「OK」を押します。いまの内容は、`%AppData%\NovelKeeper\backups` に控えを残してから置き換わり、アプリが自動で起動し直します。  
別のPCに戻した場合は、「ログイン設定」タブでログインし直してください。そのPCで使えない起動設定（ファイルがない、Steam や DMM Game Player にゲームがないもの）は外れるので、「ゲーム起動設定」タブで設定し直してください。

**Q. 自動バックアップはある？容量は大丈夫？**

A. あります（初期はオン）。「データ出力」タブ →「バックアップ」の「① 自動バックアップ」で、オン・オフ、間隔（毎日／7日ごと）、残す世代（3～14、初期は7）を選べます。作品の一覧・プレイ時間（`games_日付.db`）と設定（`config_日付.json`）を `%AppData%\NovelKeeper\backups` に控えます。ログイン情報は含みません。  
- 前回から変わっていないときは、作りません。
- 古いものは、設定した世代を超えると完全に削除されます（ゴミ箱には残りません）。戻す前の控え（`before_…`）は最大5個、フォルダ全体で50MBまでです。
- ドライブの空きが500MB未満のときは、作りません。
- ボタン：「今すぐバックアップ」／「自動バックアップから戻す…」（一覧から選びます。確認のうえ、いまの内容を控えてから置き換えます）／「バックアップのフォルダを開く」／「データの検査」。
- 起動のたびに作品データの検査をして、壊れていたときは、戻すかどうかを聞きます（自動では戻しません）。

**Q. 同期のたびに「食い違い」の確認が何度も出る**

A. 確認の画面で「以降の〜の食い違いにも、同じ選択を使う」に☑して選ぶと、その同期の間は、同じ種類の食い違い（クリア日・得点・長文感想）を聞かずに同じ側で処理します。

**Q. 同期で「批評空間の記録が0件でした」と出る**

A. 批評空間がメンテナンス中などで、記録を取得できていない可能性があります。［いいえ］で中止して、しばらくしてからやり直してください。

**Q. 不具合の原因を調べたい**

A. `%AppData%\NovelKeeper\log.txt` に動作の記録が残っています（パスワードは記録しません）。問い合わせるときは、このファイルを添えてください。

**Q. 「未反映の項目」が消えない／批評空間で変えた内容がツールに取り込まれない**

A. ツールで変更した内容が批評空間に反映されないまま残っていると、同期ではツールの内容が優先されます。詳細欄の「未反映の変更を破棄」を押してから「⇅ 批評空間と同期」を押すと、批評空間の内容を取り込めます。

**Q. 未プレイに戻したのに、批評空間のプレイ済が外れない**

A. 批評空間は、得点が入っているとプレイ済を外せません。ツールの得点欄も空欄にして保存すると、批評空間の得点も空にして反映します（確認ダイアログが出ます）。

**Q. アンインストールしたい**

A. ①「詳細設定」タブで「Windows の起動時に自動で起動する」をオフ → ② 通知領域のアイコンを右クリック →「終了」→ ③ `NovelKeeper.exe` と `%AppData%\NovelKeeper` フォルダを削除。
